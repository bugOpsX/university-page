# Marwadi University Visiting Page

This is a simple university visiting webpage created using **HTML** and **CSS**. It provides basic information about Marwadi University in a clean and responsive layout.

## Features

* Simple and clean design
* Responsive layout
* Easy navigation
* Basic university information display

## Technologies Used

* HTML5
* CSS3

## How to Use

1. Download or clone the repository
2. Open the `index.html` file in your browser

## Purpose

This project is created for learning and practicing basic web development skills.
